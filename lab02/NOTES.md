Рабочая папка — это место, где лежат файлы твоего проекта.
Индекс (staging area) — это «черновик» коммита: туда ты добавляешь файлы командой git add, чтобы Git запомнил, какие изменения пойдут в следующий коммит.
Коммит — это «снимок» состояния проекта на момент времени, с комментарием, что именно ты сделал.

Git — это локальная система контроля версий на твоём компьютере: она хранит историю изменений, ветки, коммиты.
GitHub — это удалённый хостинг для репозиториев: он позволяет хранить проект в интернете, делиться им и работать в команде.

git status — показывает текущее состояние: какие файлы изменены, какие добавлены в индекс, есть ли неотслеживаемые файлы.
git diff — показывает изменения в файлах, которые ещё не добавлены в индекс.
git diff --staged — показывает изменения, уже добавленные в индекс (готовые к коммиту).
